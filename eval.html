Evaluation

Overall, we are very pleased with how the app turned out. The login and registration system was completed and look great while functioning amazingly well! The user can create accounts on the registration window and sign in on the sign in window and receive clear error messages for incorrect credentials or for making their password too short; which greatly improves the overall user experience and makes the app easier to use. The game library was implemented aswell, which you can access when you log in. Though it currently only displays game titles and the genre rather than full description pages as originally planned. It is also hard coded so every user that logs in has the same amount and the same games. Several improvements could make the app better going forward fixing the issue like including better search functionality because the games are hard coded, recognizing game abbreviations like "CS2" for Counter Strike 2 or "GTA" for Grand Theft Auto which are currently unrecognized and result in a blank and unhelpful page and a game rating, like RPG, FPS etc review system like with stars like on the actual steam platforms game pages and perhaps most importantly and as mentioned previously; an actual dynamic game library which is linked to your account on the CSV file so everyone doesn't have the same games in every account, and which can be added to by adding games to your library to further improve and the platform closer in functionality to the actual steam platform.

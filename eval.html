Evaluation

Overall, we are pleased with how the website turned out. The login and registration system was completed and look great! Users can create accounts, sign in, and receive clear error messages for incorrect credentials. The game library was implemented, though it currently only displays game titles rather than full description pages as originally planned. It is also hardcoded. Additional improvements could include smarter search functionality for example, recognising abbreviations like "CS2" for Counter Strike 2 and a game rating or review system to further improve and enrich the platform.

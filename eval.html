Evaluation

Overall, we are very pleased with how the app turned out. The login and registration system was completed and look great while functioning amazingly well! The user can create accounts and sign in and receive clear error messages for incorrect credentials or for making their password too short; which greatly improves the overall user experience. The game library was implemented, though it currently only displays game titles and the genre rather than full description pages as originally planned. It is also hardcoded so every user that logs in has the same amount and the same games. Several improvements could make the app better going forward fixing the issue like including better search functionality because the games are hardcoded, recognising abbreviations like "CS2" for Counter Strike 2 which are currently unrecognised and result in a blank page and a game rating, review system like with stars and perhaps most importantly and as mentioned previously; actual dynamic game library which is linked to your account, so everyone doesn't have the same games in every account to further improve and enrich the platform.
